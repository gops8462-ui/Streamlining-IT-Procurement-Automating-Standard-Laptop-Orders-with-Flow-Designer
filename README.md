# Streamlining-IT-Procurement-Automating-Standard-Laptop-Orders-with-Flow-Designer
A ServiceNow solution that automates Standard Laptop procurement using Flow Designer. When a Standard Laptop request is approved, the flow automatically creates a Catalog Task and assigns it to the Hardware team for configuration. This removes manual effort, prevents missed tasks, and speeds up laptop delivery.
